# One quote per line, as `text|author`. The greeting will print a line with no `|` on its
# own, but every line here carries an author. Blank lines and lines starting with `#` are
# ignored, so this file can be grouped and annotated freely.
#
# The greeting draws one at random per terminal. Set DOTS_QUOTES_FILE in
# ~/.bash_profile.local to read a different file entirely.
#
# Only one `|` per line: the parser splits on the first one, so a second would land in the
# author.
#
# On attribution. Where a saying is genuinely collective the source names the tradition
# rather than a person: `Japanese proverb`, `Zen proverb`, `Latin maxim`. Several popular
# quotations are credited here to whoever actually wrote them rather than to the famous
# name they are usually hung on: `We are what we repeatedly do` is Will Durant summarising
# Aristotle, `It is not the strongest of the species` is Leon C. Megginson and not Darwin,
# `I disapprove of what you say` is Evelyn Beatrice Hall and not Voltaire, `We shape our
# tools` is John Culkin and not McLuhan, and `Be kind, for everyone you meet` is Ian
# Maclaren and not Plato. A few are paraphrases in wide circulation rather than exact
# transcriptions.
